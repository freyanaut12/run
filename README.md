Drop your JPG/PNG photos here with these exact filenames so they match what
`index.html` already references — no code editing needed. Each project has
3 photo slots, shown as a slider with dots and prev/next arrows.

## Notes
- Any common web image format works (`.jpg`, `.png`, `.webp`) — just update
  the `src="images/...jpg"` extension in `index.html` to match if you don't
  use `.jpg`.
- You don't need all 3 photos per project. If only 1 loads, the card just
  shows that single photo with no dots/arrows. If 2 or 3 load, dots and
  arrows appear automatically and the slider auto-advances every ~3 seconds
  (pauses while hovered).
- If none of a project's photos are uploaded yet, that card simply shows its
  plain placeholder background — nothing breaks or looks broken.
- Recommended size: at least 1200px on the longer side, compressed for web
  (keep each file under ~300KB where possible) so the page stays fast.
